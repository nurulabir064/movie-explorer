 # Movie Explorer

A responsive Movie Explorer application built with React and TVMaze API.

## Features
* Browse available shows
* Search shows by title
* Responsive movie/show cards
* Show poster, title, release year and rating
* View detailed information in a modal
* Responsive design for mobile and desktop

## Technologies
* React
* JavaScript
* CSS
* TVMaze API
* Vite

## API

TVMaze API

## Run Locally

```bash
npm install
npm run dev
```
